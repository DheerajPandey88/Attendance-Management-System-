📘 Project Title: Attendance Management System

 📝 Short Description:-
This system is designed to streamline classroom operations by enabling teachers and students to manage attendance, homework, and academic records efficiently. It allows administrators to add students, assign subjects, and schedule lectures. Teachers can take subject-wise daily attendance and assign homework, while students can download homework PDFs and submit their work directly through the platform. The system also supports lecture time management and generates attendance reports for review.


 ✅ Key Features
* Student Management: Add, update, and organize student profiles.
* Daily Attendance: Teachers take subject-wise attendance with time stamped records.
* Homework Module:
  - Teachers assign homework.
  - Students download homework in PDF format.
  - Students submit homework daily via upload.
* Lecture Scheduling: Fix lecture times per subject and notify students.
* Teacher Management: Add new teachers and assign them to subjects.
* Report Generation: Export attendance and homework records as PDFs.
